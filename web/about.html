wfform

A browser workspace for free OpenRouter models

wfform means Wrapper for Free Open Router Models. It helps you discover AI models with free pricing in the OpenRouter catalog, inspect their capabilities, and chat with the model you choose.

Open wfform

Choose a model with context

The catalog refreshes on launch and can be refreshed manually. Search models and inspect their descriptions, context lengths, pricing, supported inputs and outputs, and request parameters. Recent health observations help explain availability; they cannot guarantee the next response.

Chat selection is limited to compatible models whose applicable prices are verified as zero. A changed or unavailable model requires a new valid selection. The app does not silently switch to paid models.

Continue your conversations

Stream replies, cancel a request, edit and resend an earlier message, or start a new conversation with another model. Conversation history and drafts stay in this browser. You can archive, restore, delete, export, and import conversations. Data is not automatically synchronized between devices or browser profiles.

Work with supported files

Preview Markdown, JSON, YAML, source code, and other supported text documents. Image, audio, video, and file inputs depend on the selected model and provider. Model details show capabilities, and the composer checks attachment compatibility and limits before sending. Uploaded or generated code is displayed as text, not executed.

Get started

  1. Open the app and add your OpenRouter API key in Settings.
  2. Choose a compatible free model from the current catalog.
  3. Write a message, add supported attachments if useful, and send.

OpenRouter account requirements, rate limits, model availability, and provider limits still apply. Free pricing does not mean unlimited usage. Requests go directly from your browser to OpenRouter; an internet connection is needed for chat.

Install it or use a browser tab

wfform is a progressive web app with light and dark themes and layouts for narrow or wide windows. Supported browsers can install it. After a successful online load, its offline shell and cached model catalog remain available when browser storage is retained; remote chat is unavailable offline.

wfform is an independent application and is not affiliated with OpenRouter.
