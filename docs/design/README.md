# Design and architecture decisions

[DESIGN.md](DESIGN.md) describes the implemented interaction/system design and the active extension boundary.

| Accepted ADR | Decision |
|---|---|
| [ADR-0001](ADR-0001-flutter-browser-boundary.md) | Flutter client with direct structured API access |
| [ADR-0002](ADR-0002-local-normalized-history.md) | Normalized browser-local conversation history |
| [ADR-0003](ADR-0003-content-addressed-pwa.md) | Explicit content-addressed PWA releases |
| [ADR-0004](ADR-0004-agent-workspace-boundary.md) | Agent operations without changing the application stack |

ADRs record established choices; their acceptance does not mark the current roadmap complete. Supersede an accepted ADR with a new linked decision when the choice changes.

[DESIGN.template.md](DESIGN.template.md) and [ADR.template.md](ADR.template.md) remain clearly labeled reusable forms, not unfilled product deliverables.
