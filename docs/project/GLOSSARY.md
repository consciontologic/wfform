# Glossary

| Term | Meaning |
|---|---|
| Free-price candidate | Applicable reported prices validate as zero; provider availability remains separate. |
| Unresolved price | Observed exact `-1` marker, conservatively excluded where applicable, never converted to zero. |
| Quarantine | Exclude/report an invalid catalog entry while retaining valid entries. |
| Health/probe | Recent model observation / small selected-model inference, not a guarantee of future or media success. |
| Allowance/cooldown | Advisory counters / enforced wait; neither schedules an automatic resend. |
| Context boundary | Explicit first user turn included in new requests; older saved history remains. |
| Output reserve | Local token estimate until the user explicitly sets a supported request limit. |
| Draft/chat | Unsent work / a conversation whose user content crossed actual dispatch. |
| Recovered copy | Separate identity preserving conflicting local work without overwriting another tab. |
| Archive | Read-only saved history, restorable or explicitly deletable; not a backup. |
| Origin | Scheme, host and port defining browser storage boundaries. |
| PWA generation | Hash-verified static shell cache; public releases/packages use SemVer. |
| Tool/MCP | Requested program action / protocol for listing and invoking tools. |
| wfformcomp | Optional allowlisted local CLI/stdio bridge; not an OS sandbox. |
| CodeGraph | Enabled project-local source-navigation MCP/CLI, independent of application runtime. |
| xops | Repository shell/Python operations, not a backend. |
| Mocked/live check | Controlled fixtures / actual service or runtime evidence; report separately. |
